# Competition software release gate

The product is M4KE, a general small-toy design studio. The sound car is a software acceptance benchmark. Qwen must design it from a fresh prompt, select host verification tools and repair failures itself; a hand-engineered preset does not count. The user will build it later; no physical build, filming, purchase or print is required from this agent.

## Required before calling the software release ready

- [ ] Freeze and deploy a tested source/bundle revision on DGX without modifying the teammate database.
- [ ] Actual local Qwen request, bounded JSON generation and native CAD workflow tested; no silent fixture substitution.
- [ ] Car benchmark: matching CAD, named conditional physics/controller checks, revision-bound print parts, BOM and illustrated instructions.
- [ ] General-toy benchmark beyond the car; retain any failed attempt and unsupported-function boundary.
- [ ] Actual browser checks at desktop and mobile widths; export/readback hashes and no hidden cloud dependency.
- [ ] Immutable source ZIP passes allowlist/hash checks and isolated setup regression; incomplete setup dependencies are explicit.
- [ ] README describes architecture, DGX/model/skills, deployment, demo steps, evidence classes and limits.
- [ ] Team TXT handoff updated with exact files, release and remaining manual submission tasks.

## Not claimed by this software release

Actual printing, electrical commissioning, measured speed/stopping distance, calibrated sound pressure, child safety, complete procurement quotes, full contact/thermal/FEA simulation, or final public submission. Qwen reviews and orchestrates; host calculations are the evidence, not Qwen's assurance.

## Team submission handoff

Owner reviews/publishes the source link; video teammate records and uploads the demo; team supplies the photo and optional development article. No fabricated URLs or automatic uploads. The submitted source README must include at least500Chinese characters, deployment/optimization/skills, and the actual NVIDIA/model/tool inventory. See README.zh-CN.md, DEPLOYMENT.md and INVENTORY.md.
