## 项目介绍

M4KE 是面向非工程师创作者的通用小型玩具设计工作台。产品不是一辆由开发者预先画好的小车，也不是一个只能播放漂亮模型的网页。用户从自然语言表达功能，例如“声音足够大时前进、安静时停止驱动的小车”，本地 Qwen 应主动询问必要问题、选择有来源的组件、明确可修改的假设，再生成结构化设计并调用工程工具。声控车只是工作台的首个端到端测试对象；不同玩具请求不得被悄悄替换成同一个小车模板。

核心运行环境是 NVIDIA DGX Spark。浏览器显示需求访谈、三维模型、验证报告、装配教程与下载入口；DGX 上的 Node 服务保存版本化项目，Ollama 运行本地 Qwen，CadQuery / Open CASCADE 将受限数据变为原生实体。准备阶段可以联网下载依赖、模型权重和厂家资料；资源准备完成后，模型推理、设计、目录查询、计算、CAD 与切片不需要云模型 API。用户在家通过自己的 SSH 通道访问 DGX，远程访问需要网络，但计算并未转移到云端或浏览器上的另一个模型服务。

本地新候选版通过 `studio-skills.mjs` 加载六个有哈希的运行时技能：设计、架构重规划、验证工具选择（runtime-plan）、验证审阅、有界修复与来源支持的 Dyson 式迭代方法。架构重规划与目录配合检查尚未随当前线上界面部署；各阶段实际使用的文件哈希保存在运行记录中。工具选择是一次独立的本地 Qwen 阶段：它只能增加受支持、与原需求绑定的检查，不能删除已有检查或自行填入结果。这里的核心思想是先暴露最大的不确定性，再用能够证伪的工具检查，保留失败，并让 Qwen 在有界循环中修复设计。技能是提示词与工具契约，不是模型权重微调，不代表 James Dyson 本人的身份或背书。模型可以提出设计与检查请求，但不能自己输出“验证成功”代替工具运行。开发者负责实现工作台，而不是在后台手工替模型设计演示小车。

几何接口只接受严格、有限的 JSON：基本实体、单一打印件内的有界融合、孔、凹槽、圆角和经过哈希验证的来源 STEP。没有模型生成 Python、Shell 或任意脚本的执行入口。Qwen 可声明与需求绑定的验证请求，让原生工具检查整体包络、直圆柱销与孔的轴线及实际插入长度、或有限角度采样下的旋转干涉。小车的扭矩、速度、牵引、电气和简化梁筛查使用明确公式与来源或假设输入。检查失败会反馈到修复阶段；修复不得删除原需求、降低既定测试条件或用另一个未批准型号替代原组件。通过某个检查不代表所有功能都已通过。

源模型的尺寸、坐标、文件身份和接口状态与自定义打印件分开管理。队友负责模型数据库和比例核对，工作台通过只读、版本固定的接口接入；不会缩放厂家模型来适配错误结构。候选被收录、尺度检查通过、静态碰撞网格可建立，与可装配、可运动、可制造是不同状态。Qwen 得到的候选搜索上下文携带来源哈希和限制；未获准的候选不能自动升级为生产零件，也不能把共享一个 CAD 文件的不同型号当作电气等价品。

输出是同一设计修订的 STEP、分件 STL、装配文件、BOM、计算与验证记录、装配插图及离线 HTML 教程。带电玩具还使用结构化 electrical 网表，把组件身份、端子、连接、导线建议和控制引脚绑定在同一个修订中，生成带标签的二维 SVG 接线图、逐线 CSV 表、三维导线叠层及匹配的固件配置。三维线路只使用有明确锚点的连接，端子位置仍标为模型假设；缺少锚点不改用零件中心伪造接线，爆炸视图会隐藏线路。通过 UI 点击线路或表格，可同时定位两端组件与端子。固件输出默认禁用，不能把下载固件等同于已完成通电调试。打印机、喷嘴、材料由用户明确选择，H2C 仅是选项而非默认值。可选 DGX 切片与只读打印机状态查询不意味着自动上传或打印。相对响度不是校准声压级，停止驱动不是瞬间机械刹停；硬件噪声、真实公差、强度和最终行为需要用户以后实际搭建测量。

比赛验收要求是 **Qwen 从新需求开始，通过工作台完成设计、工具检查和修复，并交付一致的模型与说明**。预编译机构套件只能作为明确标注的参考，不能冒充这个验收的成功。团队会在软件完成后自行制作实物，视频由队友负责；软件检查、采样运动检查、条件计算和实际物理试验在界面和文档中分别表述，不制造已经完成实测的印象。

## 快速开始与技术说明

1. 在新的 DGX 目录解压经过校验的源码包，按 [部署说明](docs/submission/DEPLOYMENT.md)准备依赖、模型和来源资源。
2. `python3 scripts/setup-submission.py --smoke`执行干净依赖安装与软件/原生 CAD 检查。
3. 检查实际本地模型；本环境标签 `qwen3.8:27b` 的元数据为 `qwen35`、27.3B、Q4_K_M。标签不是官方“Qwen3.8”发布名称的证明。
4. 配置 `OLLAMA_URL=http://127.0.0.1:11434`、`QWEN_MODEL=qwen3.8:27b`、`PORT=4173` 后 `npm start`。无对应本地模型时明确报错，不静默替换或转云端。
5. 浏览器进入 Intent，新建普通 Qwen 项目。回答问题，运行流水线，在 Design / Verify / Build / Export 检查同一修订并下载。

参见 [实际依赖与 NVIDIA/模型/技能清单](docs/submission/INVENTORY.md)、[验证命令](docs/submission/VALIDATION.md)、[比赛发布清单](docs/submission/competition-release-checklist.md)和[许可范围](docs/submission/LICENSE-NOTES.md)。已实现的优化是本地量化模型运行、结构化输出、受限工具、版本与哈希绑定、有界重试、传输压缩和浏览器模型缓存；没有声称使用 TensorRT、Isaac 或尚未集成的赞助商 SDK。

## 数据与交付边界

源码包不含模型权重、厂家 CAD、原始供应商网页、队友数据库、私人地址、口令、密钥或已安装依赖。单独的来源重建工具会下载并复核新的厂家观察，保留历史哈希与新证据关系；它只产生待审候选，不偷偷激活新目录。历史缓存回放不是新的联网下载证明。立创采购数据需要真实、型号匹配、带日期的来源；提供一个爬虫包不等于已经连接了嘉立创 EDA PCB 设计 MCP。

团队负责最终源码发布、视频链接、合照及可选开发文章。这里不伪造投稿链接或自动上传。软件发布状态以对应版本的实际验收记录为准，不以本文的介绍性文字为证据。
