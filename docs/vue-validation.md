## 已覆盖的关键行为

- 五阶段、命名工作区、刷新恢复；草稿不自动进入正式验证。
- 打印件和采购件共享选择、多选、活动零件、显隐和 AI 上下文。
- 显隐独立持久化，不改变设计版本、哈希或导出；隐藏几何不可射线拾取，线路跟随端点。
- 只读问答冻结选择和版本；候选确认前不覆盖，过期候选拒绝应用。
- 需求改变后必须重新生成草稿，不用旧规格验证新需求。
- 标准视图、鼠标和快捷键；文本输入不被视口快捷键截获。
- 旧版本缺少说明、模型未配置、断线、原生文件缺失 / 哈希错误、验证哈希失配都有明确状态。
- 失败 / 失配证据隔离；诊断导出标识，禁止装配确认与切片；不自动购买或发送打印。
- 桌面和手机截图目检，弹窗焦点 / Escape、语言、减少动态和侧栏抽屉。
