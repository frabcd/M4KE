
## Native library
`nativeLibrary` supplies exact SHA-bound `{type:"library",sourceSha256:"..."}` geometry. Never invent identities. Imports rehash/snapshot STEP plus notices, reject held sources, and preserve original mm origin (bounds may be off-centre); part pose transforms that frame. No rescaling, recentering or fillet/hole/pocket edits. Printed imports require one positive solid and normal print gates. Purchased multi-solids have UNKNOWN fit, mass, interfaces and ratings. Repair cannot swap source identity. Pi/Pico requires explicit user selection. MCP search_model_library/get_model_source/get_static_collider expose full local sources; library availability never grants engineering approval. Colliders are fixed-only, metres/Y-up, original origin; no dynamic/print qualification.
